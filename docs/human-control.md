# 用户控制电脑的边界

用户对电脑的实时控制优先于任务持续推进、技能、浏览器工作流和先前交互授权。

1. 用户输入或频繁点击、滚动、拖拽、使用快捷键、切换窗口时，禁止自动点击、输入、聚焦、窗口激活、前台启动、手机镜像控制，以及所有可能影响宿主 UI 的交互自动化。
2. 用户报告抢焦点、不希望被控制，或出现活动信号时，立即停止交互动作并释放桌面，不等待重复要求。
3. 活动信号只中断 GUI 控制，继续有用的后台连接器、API、CLI 工作。没有可继续的后台工作或用户明确要求暂停时，才停止整个任务。
4. 不截图、轮询或监视桌面以判断用户是否空闲。
5. 后续活动覆盖先前任务授权；只有用户明确允许恢复，或在活动结束后发出新的具体交互请求，才能恢复 GUI 操作。
6. 有界交互结束或中断后，立即终止任务范围内的控制会话、helper、monitor、relay、延迟重启和 keepalive，核实没有未来会抢焦点的来源；不终止无关运行时或主客户端。进一步交互需要新的明确请求。
