# 测验回顾清单

在课时中选择选项，再点击“检查答案”。答错的课时会进入“我的学习库 → 测验回顾”；从清单回到本课检查当前题目，答对后移出，也可以手动移除。清单记录回顾安排，不是成绩、答题历史或能力认证。

## 检查与课程完成

仅选择选项不会显示答案解释、写入回顾记录或获得完成资格。检查后显示本次反馈；未完成的课时需明确检查答对，并确认全部实践验收项，才能手动标记完成。再次更换选项会取消本次检查资格，返回原选项也须重新检查。

测验属于共同课时，切换 TypeScript / Go / Python 参考语言会保留当前选择与检查结果，不生成三条回顾。离开课时或刷新后不恢复作答状态。同 ID 的题目、选项顺序、答案或解释发生变化，旧检查资格立即失效；改回原内容也不能恢复旧资格。历史回顾只引导检查当前题目，不声称当前版本曾答错。

已完成课时答错后仍保留完成标记，也可以加入回顾。检查和移除只修改回顾清单，不写入笔记、证据、语言实践或实验运行历史；答对不会自动标记完成。

## 清单与容量

最多 64 条，按课时去重，重复答错保留首次加入时间。满额时仍显示题目反馈，但会明确提示新课未加入；已有记录可以检查答对或手动移除，释放名额。列表按加入时间及课时 ID 稳定排序，日期标注 UTC。

可用课时显示当前标题和“回顾本课”入口，直接定位测验。当前目录找不到、重复或路线归属冲突的课时不生成链接；保留原 ID 和时间，可逐条移除或继续导出。可回顾数量与不可用数量分开显示，空清单不代表全部课程已掌握。

## 本地保存与备份

沿用 `deep-ai-station:v1`，新增可选 `quizReview` 数组，每项仅保存 `lesson_id` 和 `added_at`，不保存选项、题干、正确答案或通过状态。ID 限合法 Agent/全栈课时格式、100 字符以内；时间须为规范的毫秒 UTC ISO 字符串。拒绝重复、额外字段、稀疏项、非法日期或超过 64 条的数组。

旧 v1 备份没有回顾字段时为空，不从完成、实践或笔记推断历史答题。格式合法但已移除的课时仍可导入。错误导入整份拒绝，当前记录不变；新字段不能保证被尚未更新的旧客户端接受。

检查与手动移除在写入前读取最新有效存储，减少未送达的其他标签页更新被覆盖。保存失败时保留当前内存，并显示全局警告，应先导出再刷新；这不是跨标签事务或账号云同步，真正同时写入仍可能互相覆盖。JSON 导入仍限 2,000,000 字节，超限完整导出的恢复边界见[实践证据文档](practice-evidence.md)。本功能不调用模型或沙箱，不需要密钥。
