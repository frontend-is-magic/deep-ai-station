# 实践证据卡

下载实验后，在对应课时记录自己实际执行的版本、命令、成功结果、失败案例与未验证事项。十八节实验课和六节毕业课共用这张卡；全栈服务端实验按 TypeScript / Go / Python 分别记录，公共 React 前端实验固定 TypeScript，Agent 循环、MCP、工具安全、状态机、文档切分、回归、记忆课和毕业课固定 Python。包内 `EVIDENCE.md` 仍可独立使用，平台不会启动练习代码。

## 入口与归属

先在路线页选择服务端语言，查看“可运行实践清单”。默认只看未记录：同一实验只列一组，任一关联课未记录就保留整组；展开后可看到各课自己的状态，进入对应课时下载区。关闭筛选可回顾已记录实验。Agent 固定 Python；该清单目前汇集十三类实验，不包含毕业骨架。

完成实践后，在原课程界面确认成功与失败样例，再记录该语言实践；回到清单会反映结果，撤销后会重新出现。下载、填写证据或完成共同课程均不会自动改实践状态。

## 集中回看

学习库的“实践证据”（`/library?tab=evidence`）按更新时间倒序展示现有记录，可筛选路线、语言及“填写了未验证说明”。说明写“无”也会命中，此筛选不判断是否通过。展开可查看五项原文；代码、HTML 和 URL 都只作为文字，不执行或自动生成外链。

当前目录中唯一且归属/语言一致的课时提供打开课程链接，全栈保留记录语言。目录不再包含、归属冲突、不支持该语言或旧格式 ID 的记录仍可查看和导出，没有猜测课程链接；空白旧记录也不会被删除。索引只读，不自动完成课时或实践。课程 API 整体失败时仍受现有页面加载边界约束，不提供离线课程目录。

每条记录可导出 JSON，包含原有八个字段与原始值；文件名只使用固定前缀和合法语言。导出前重新读取最新同课/语言记录：已更新或导入则导出当前值，已删除则拒绝下载并同步视图。该文件仅供查阅，不能直接用于恢复；完整恢复仍使用学习设置的 v1 备份。

## 保存与恢复

记录保存在当前浏览器 `deep-ai-station:v1` 的可选 `evidence` 数组，以课程 ID 和语言为键。旧版没有证据或只有原 24 条的 v1 备份仍可导入，不丢笔记、完成记录、收藏或历史；超过 24 条的新备份不能保证被旧客户端接受，这只是新版读取旧备份的兼容。

每次字段编辑、证据 Markdown 导出和整份导出前读取最新有效存储，减少其他标签页更新尚未送达时的覆盖。字段全文还绑定显示时的记录版本；其他页面导入或清空后，旧字段编辑拒绝保存并同步最新记录，须重新填写。Markdown 导出读取最新同课同语言记录，已删除或为空则停止，不下载旧快照。处理 `storage` 事件时读取当前值，而不是把延迟到达的旧事件载荷直接写回页面。格式错误的外部值不覆盖当前内存，真实删除按空记录处理。这不是跨标签事务或云同步；两个标签页真正同时修改时仍可能最后写入覆盖前一次。

浏览器存储失败会显示全局提示，当前内容留在内存供导出；后续字段编辑不会用旧磁盘值覆盖尚未保存内容。存储恢复后再次编辑可保存保留的内容。刷新仍可能丢失尚未持久化的修改，应先导出。

## 课程导出与完整备份

单课 Markdown 包含当前课时、语言、时间及五项内容；实验卡额外标注实验名称，毕业卡保留毕业标题。用户内容放入动态长度的纯文本围栏，反引号、HTML 与换行按原文保留。只有空白时禁用下载，导出不代表平台核验成功。

学习设置中的 JSON 导出保留整份记录和其他学习数据。导入上限仍是 **2,000,000 字节**，还须通过结构、字段长度、重复组合与容量校验；拒绝导入不会改变当前数据。即使所有字段各自合法，整体内容或 JSON 转义也可能超过该字节限制。此时仍允许完整导出用于保留数据，并明确提示不能直接导回当前版本；请保留原文件，再精简副本后导入。平台不会静默截断或擅自提高导入限制。

不要在证据、笔记或备份中填写 API Key、访问码、数据库连接串或其他认证信息。证据由学习者自行填写；自动测试只验证保存、隔离和恢复流程，不能证明填写的命令已经执行或生产环境通过验收。

React组件与Jotai两课共用一个TypeScript实验包，两课分别保存证据和实践。即使当前服务端参考为Go/Python，公共前端下载与证据仍明确使用TypeScript；原参考语言与旧实践记录不会被改写或算作该实验完成。Go/Python视图在实验区提供单独的TypeScript确认，页下原“本课实践记录”继续记录服务端参考实践；选择TypeScript时复用原控件。

路线清单的公共前端组只读取这两课的TypeScript实践。证据库中该实验的TypeScript入口保持当前服务端偏好。十三类实验、十八个课时共36个实际课时/语言组合，加毕业课12种合计48，仍使用原48条证据容量与v1备份。下载与实验中勾选教学卡片都不会替平台记录完成。
