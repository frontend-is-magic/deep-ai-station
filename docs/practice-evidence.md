# 实践证据卡

下载实验后，在对应课时记录自己实际执行的版本、命令、成功结果、失败案例与未验证事项。十一节实验课和六节毕业课共用这张卡；全栈按 TypeScript / Go / Python 分别记录，Agent MCP、工具安全课和毕业课固定 Python。包内 `EVIDENCE.md` 仍可独立使用，平台不会启动练习代码。

实验卡就在下载区下方，显示实验名称和当前语言；同一实验对应的不同课时也分别记录。毕业卡入口、标题和原记录保留。字段不会预填成已执行的结果，查看、下载或填写证据不自动完成课程、验收确认或语言实践。

记录最多 48 条，全部课时与语言共用。当前九节全栈实验课的 27 种语言组合、Agent MCP 与工具安全的 2 种组合和六节毕业课的 12 种组合可同时保存（共 41 种）。代码版本最多 200 字符，其余四项各 2000 字符。满额时已有记录仍可编辑；清空当前记录的全部五项内容会移除它并释放名额。未填写的新记录不占位；单个字段清空不会删掉其他字段。

## 保存与恢复

记录保存在当前浏览器 `deep-ai-station:v1` 的可选 `evidence` 数组，以课程 ID 和语言为键。旧版没有证据或只有原 24 条的 v1 备份仍可导入，不丢笔记、完成记录、收藏或历史；超过 24 条的新备份不能保证被旧客户端接受，这只是新版读取旧备份的兼容。

每次字段编辑和整份导出前读取最新有效存储，减少其他标签页更新尚未送达时的覆盖。处理 `storage` 事件时读取当前值，而不是把延迟到达的旧事件载荷直接写回页面。格式错误的外部值不覆盖当前内存，真实删除按空记录处理。这不是跨标签事务或云同步；两个标签页真正同时修改时仍可能最后写入覆盖前一次。

浏览器存储失败会显示全局提示，当前内容留在内存供导出；后续字段编辑不会用旧磁盘值覆盖尚未保存内容。存储恢复后再次编辑可保存保留的内容。刷新仍可能丢失尚未持久化的修改，应先导出。

## 两种导出

单课 Markdown 包含当前课时、语言、时间及五项内容；实验卡额外标注实验名称，毕业卡保留毕业标题。用户内容放入动态长度的纯文本围栏，反引号、HTML 与换行按原文保留。只有空白时禁用下载，导出不代表平台核验成功。

学习设置中的 JSON 导出保留整份记录和其他学习数据。导入上限仍是 **2,000,000 字节**，还须通过结构、字段长度、重复组合与容量校验；拒绝导入不会改变当前数据。即使所有字段各自合法，整体内容或 JSON 转义也可能超过该字节限制。此时仍允许完整导出用于保留数据，并明确提示不能直接导回当前版本；请保留原文件，再精简副本后导入。平台不会静默截断或擅自提高导入限制。

不要在证据、笔记或备份中填写 API Key、访问码、数据库连接串或其他认证信息。证据由学习者自行填写；自动测试只验证保存、隔离和恢复流程，不能证明填写的命令已经执行或生产环境通过验收。
