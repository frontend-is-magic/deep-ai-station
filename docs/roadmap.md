# 持续迭代清单

优先完成用户可操作的学习闭环，再提高逐课实验深度与生产可靠性。

1. 初始闭环：双路线、信息流、课程测验与笔记、教学工作流、静态代码检查、多模型服务端适配、个人记录导入导出。
2. 课程深化：每节课独立测验、专用参考代码、可验证实验任务与失败样例。
3. 实验运行：受控 E2B 多语言模板或等价隔离服务，编译与执行输出，超时终止和销毁；主机永不执行用户代码。
4. 产品可靠性：真实 token streaming、共享限流、集中 usage 配额、运行取消向供应商传递。
5. 个人账户与云同步：明确用户授权、PostgreSQL 数据约束、迁移与跨用户访问测试。
6. 交付：持续小提交、GitHub CI、Vercel 预览与生产验收、Notion 开发文档和 wiki 同步。

人工凭据事项集中到独立对话，不阻塞其他开发；禁止使用重置卡。
