# 免费 Agent 工具契约实验

在“结构化输出与校验”或“工具契约与 Function Calling”课点击“运行工具契约实验”。也可从 Playground 的“工具契约”模式选择支持的课程。实验使用课程 Agent 的真实参数模型与只读实现，无模型、沙箱、账户或外部请求。

## 先跑成功，再主动制造失败

1. 用 knowledge_search 和 {"query":"MCP"} 查看至多三条实际课程资料，比较 source 与 operation_id。
2. 改成没有匹配的关键词。合法空结果仍是成功调用，不应被伪造成工具故障。
3. 加入 "limit":3 或把 query 改为数字，观察 invalid_arguments。正式 schema 不接受参考简例中的 limit，界面显示当前服务端契约。
4. 输入重复 query 字段、非对象 JSON 或缺少引号，观察 invalid_arguments_json。界面发送原始参数文本，不能提前解析并丢掉重复字段。
5. 用 lesson_read 读取 agent-mcp，再试 fullstack-routing，比较同路线读取与 lesson_not_in_track；未知工具返回 unknown_tool。

参数中的 lesson_id 是读取目标；页面绑定的课时是保存笔记目标，两者互相独立。工具返回的文本是课程资料，不授予额外权限。

## 请求与结果

GET /api/playground/tool-contract 提供 tool-contract-v1 版本、现有两个工具的 schema、支持课时、固定案例和限制。POST 接收：

```json
{
  "track": "agent",
  "lesson_id": "agent-tool-contract",
  "tool_name": "knowledge_search",
  "arguments_json": "{\"query\":\"MCP\"}"
}
```

外层严格校验，未知字段与错误类型拒绝；工具名称和归属课时为1–100字符。参数原文最多4096个UTF-8字节；只允许JSON对象，拒绝重复键、非有限数字、非法Unicode与超过32层的嵌套。归属课时须真实存在且匹配路线，并属于上述两课。

| 情况                                           | 响应                                            |
| ---------------------------------------------- | ----------------------------------------------- |
| 有效工具调用，包括搜索空结果                   | 200，outcome: success                           |
| 参数解析、工具参数、未知工具、读取目标失败     | 200，outcome: rejected 与稳定 observation.error |
| 外层请求无效、参数原文过大、错路线或不支持课时 | 422，不执行工具                                 |
| 归属课时不存在                                 | 404，不执行工具                                 |
| 意外内部执行错误                               | 固定500提示，不返回原始诊断或可保存报告         |

现有中间件限制整个请求实际正文为50,000字节，超过时提前413。实验路由结果使用 no-store。每次请求有独立UUID，observation包含 read_only: true 与「run_id:1」。该标识用于追踪，不提供跨请求幂等承诺。

## 留下可复核笔记

运行后填写“观察与下一步”，明确点击保存，追加版本、工具名、原始参数、实际 observation 和个人判断。成功与拒绝都可以记录；网络错误和未完成请求不能保存。只填写公开课程参数，不写密钥或认证信息。

编辑输入、停止等待、重跑或切课都会使旧结果失效；即使传输忽略 AbortSignal，旧响应也不能覆盖新实验。前端校验契约版本、请求归属、原始输入、结果分支与 operation_id。停止等待是客户端行为，不代表撤回服务端已完成的只读查询。

保存时重新读取当前笔记，保留原文，按完整运行标记防重复；观察最多2000字符，本课笔记最多10,000字符，沿用原1000条笔记上限与v1学习备份。输入和观察用动态长度的纯文本围栏导出。不自动完成课程、记录语言实践或写入模型运行历史。

这些结果说明本次固定公开课程工具的实际行为。真实模型选择工具、MCP网络服务、写操作授权及生产身份隔离需要另外设计和验收。
